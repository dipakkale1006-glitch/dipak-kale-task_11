# Thala 7 Sneaker Store

## About the Project
Thala 7 Sneaker Store is a simple sneaker shopping website created using HTML and CSS. It has a clean design and a responsive layout.

## Features
- Landing page with navigation bar
- Featured sneaker product details
- Product image gallery
- Shopping cart and order summary
- Checkout and payment form
- Coupon code input fields
- Responsive design using CSS Flexbox and media queries

## Technologies Used
- HTML5
- CSS3
- Flexbox
- Media Queries

## How to Run
1. Download or extract the project folder.
2. Keep index.html, style.css, and README.md in the same folder.
3. Open index.html in any web browser.

## Project Files
- index.html – Website structure
- style.css – Website design and layout
- README.md – Project information

## Note
This is a front-end demo project. Cart operations, coupon calculations, and real payments are not functional. A payment gateway and JavaScript/backend integration are required for real transactions.
